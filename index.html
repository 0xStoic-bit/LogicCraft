📜 De Morgan Teoremi (Vizede Kesin Soru!)
(A • B)' = A' + B'
(A + B)' = A' • B'
📜 Yutma (Absorption) Teoremleri
A + A • B = A
A • (A + B) = A
A + A' • B = A + B
📜 Konsensüs (Consensus) Teoremi
AB + A'C + BC = AB + A'C (BC terimi fazlalıktır, düşer!)
📜 Dağılma (Distributive) Kanunu
A + (B • C) = (A + B) • (A + C)
